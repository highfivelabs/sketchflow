# L2.3: questions for the builder

**Answered 2026-11-27.** L2.3's behaviors are confirmed and its checks frozen.

L2.3 (badges and notes) is green. Seven new behaviors cover where badges
and notes sit and how they look: `steps.md` B29 to B35, plus a new rule,
R10, for stacking. Six of them describe what v0.1 already did. One found a
bug, which is fixed.

The checks render a small scene of their own and measure each badge and
note in Chrome. Twelve deliberate breaks were each caught:

- the default side for badges and for notes
- the 4 px gap
- left and right placement off center
- the badge border color
- the corner a note at a point is placed by
- `size` ignored
- the note color
- the line spacing
- left-aligned notes
- the stacking order

## 1. Badges and notes on the same side of a shape (`steps.md` R10, B35)

v0.1 drew a badge and a note on the same side of the same shape on top of
each other. So did two badges. No flow we have does this yet, but it is easy to
write, such as a "built" badge plus a note under the same box. They now
stack outward from the shape, 4 px apart: badges first, then notes, each in
the order listed. Stacking is within a step only. A note kept with
`keep: true` from an earlier step is not counted.

- (a) **Stack them** (recommended). This is what the code now does.
- (b) Leave them overlapping, and say in the README to use different sides.

Answer (Brandon, 2026-11-27): (a), stack them.

## 2. Confirm the L2.3 behaviors

`at: [x, y]` was undocumented. In v0.1 it puts the note's **top-left
corner** at the point. B32 and the README now say so. That is also how
Excalidraw places text, so we propose keeping it.

| Behavior | |
| --- | --- |
| B29 | A badge sits 4 px off its shape on its `side`, centered; below by default |
| B30 | A badge is a chip with a green border |
| B31 | A note at a shape is placed the same way |
| B32 | A note at `[x, y]` has its top-left corner there |
| B33 | Notes are in the diagram's font, size 18 and #1971c2 by default, or their own `size` and `color` |
| B34 | A note breaks into lines at its newlines, each line centered, 1.25 sizes apart |
| B35 | Badges and notes on the same side of a shape stack outward in order (ask 1) |

**Recommended:** confirm all 7 as written.

Answer (Brandon, 2026-11-27): confirmed, all 7 as written. Frozen:
`test/l2_3-badges-notes.test.js`.
