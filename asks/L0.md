## 2. Unknown keys in a flow file

v0.1 ignores keys it doesn't know, so a typo such as `focuss: [ci]` does
nothing, silently. The format is still 0.x, so this is the cheapest time
to decide.

- **(a) Recommended:** error, naming the key and the step ("step 3: unknown
  key focuss"), at L1.
- (b) Warn on stderr and go on.
- (c) Keep ignoring them.

## 3. The flow's title and the diagram's own title

The deploy example's diagram has its title drawn in it, and the flow's
`title` shows it again in the caption bar. They used to disagree. They
now match, but it is still shown twice.

- **(a) Recommended:** keep `title` optional, as it is, and leave it out of
  flows whose diagram already has a title. The README will say so.
